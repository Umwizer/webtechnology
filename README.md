# Web Technology — Course Notes & Projects

This repository is where I track what I'm learning throughout the Web Technology course, along with the hands-on projects built for each topic.

## 📚 Topics Covered

### 1. Spring Boot
- Setting up a Spring Boot project with Maven
- REST controllers, services, and repositories (MVC layering)
- Application configuration via `application.properties`
- Dependency injection with `@Autowired` / constructor injection

### 2. Hibernate
- JPA entities and annotations (`@Entity`, `@Id`, `@GeneratedValue`, etc.)
- Repository interfaces with Spring Data JPA
- `spring.jpa.hibernate.ddl-auto` strategies (`update`, `validate`, `create`, etc.)
- Entity relationships (`@OneToMany`, `@ManyToOne`, etc.)

### 3. PostgreSQL
- Connecting Spring Boot to PostgreSQL via `spring.datasource.*`
- Writing and running SQL queries
- Database design basics (normalization, keys, constraints)

### 4. Frontend (React)
- Component-based UI structure
- State and props
- Connecting a React frontend to a Spring Boot REST API
- Basic routing and forms


## 🛠 Tools
- **Backend:** Java, Spring Boot, Hibernate, Maven
- **Database:** PostgreSQL
- **Frontend:** React
- **IDE:** VS Code
